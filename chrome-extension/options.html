GitHub Guide

Ask where things are on GitHub. Uses your own Claude API key.

Create one at console.anthropic.com. It is stored only in this browser (not synced).
  • Open the panel with the floating button on github.com, or press Alt+Shift+G (change it at chrome://extensions/shortcuts).
  • Only your question and the owner/repository name from the page URL are sent to Anthropic. Page content, code and tokens are never sent.
  • The extension only points you to the right page. It never clicks anything for you.
